# Site de casamento — contexto para o portfólio

Análise estática em 12/11/2026. [Repositório](https://github.com/ArthurMMaciel/darithur-wedding-website), commit `5a0e3992c550d3493983a1dad5a7c573b9a0b66f`.

O projeto reúne em um site pessoal informações para convidados, galeria, confirmação de presença, presentes, local e contagem regressiva, segundo o README. Há uma aplicação Angular e uma Supabase Edge Function para confirmação de presença no repositório.

O texto atual do portfólio menciona migração de uma VPS para serverless por custo. A existência da função é verificável, mas a motivação, a migração, a economia e o funcionamento em produção não foram confirmados pela leitura realizada.

Fontes: `README.md`, `site-casamento/frontend-angular/` e `site-casamento/supabase/functions/confirm-presence/`. **A confirmar:** por que a arquitetura mudou, comparação de custos, papel de Arthur e experiência real dos convidados.
