# Escuta Aí Brasil — contexto para o portfólio

Análise estática em 12/11/2026. [Repositório](https://github.com/ArthurMMaciel/fala-ai-brasil), commit `ef5f8891585a29ca1d112690f0834b0df4792ae4`.

A proposta é criar um canal de escuta psicossocial no trabalho, com proteção de identidade, acompanhamento dos relatos, resposta institucional e indicadores de responsividade. A visão documentada prevê separação entre relato original e versão compartilhável e revisão humana em casos sensíveis.

O README contém declarações conflitantes: algumas seções descrevem apenas uma POC com dados simulados, outra descreve autenticação e persistência via Supabase. O contexto atualizado de outubro registra autenticação e cadastros persistidos; o código inclui serviços Supabase e migrations posteriores para manifestações e revisão. Isso demonstra evolução além do texto antigo, mas não comprova deploy, segurança de ponta a ponta nem que todos os fluxos estejam funcionais.

Fontes: `README.md`, `docs/PROJECT_CONTEXT.md`, `src/services/` e `supabase/migrations/`. **A confirmar:** motivação, participação de Arthur, estágio de uso e quais proteções de privacidade foram efetivamente validadas.
