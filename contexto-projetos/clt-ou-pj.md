# CLT ou PJ — contexto para o portfólio

Análise estática em 12/11/2026. [Repositório](https://github.com/ArthurMMaciel/clt-or-pj), commit `abf7c5d47f3a559631e3af4f8cd2ae99fc2ebe42`.

O projeto busca ajudar trabalhadores brasileiros a comparar propostas CLT e PJ, estimar equivalências e considerar benefícios, custos e reservas. A proposta prevê simulações sem cadastro e histórico para usuários autenticados.

O README descreve API em Go/Gin para cálculos, interface React, autenticação e persistência Supabase. O documento `docs/proposta-mvp.md` detalha as jornadas e as informações que o resultado pretende explicar. O repositório se apresenta como MVP em desenvolvimento; regras e resultados não foram auditados para exatidão tributária nem validados em produção.

**A confirmar:** origem da ideia, participação de Arthur, escolhas de cálculo e estágio real de uso.
